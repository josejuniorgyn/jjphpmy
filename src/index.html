Geral
Diretórios
Hosts virtuais

Cada pasta dentro do Document Root vira um site. O Windows pede permissão de administrador para atualizar o arquivo hosts.

    Backup e atualização

    O backup salva MySQL, PostgreSQL e MongoDB (os que estiverem rodando) e a pasta etc\ em C:\jjphpmy\backup.

    "Iniciar tudo" inicia os serviços instalados e marcados como Ativado.
    AtivadoServiçoPortaSSLPorta SSLStatus

    Ao salvar, os arquivos de configuração em etc\ são atualizados com as novas portas.

    Novo projeto

    O projeto é criado dentro do Document Root e já ganha o site {nome}.test. Os modelos usam o PHP, o Composer e o Node.js instalados na aba Pacotes.
